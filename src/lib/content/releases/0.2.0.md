### New

- **What's new page.** This page lists what changed in each version of Ruby. Find it under **More** on your phone or in the sidebar on a larger screen. A small dot shows when there is a version you have not read yet.
- **Update banner.** When a new version of Ruby is deployed while you have it open, a banner appears with a **Reload** button. If you have typed something you have not saved, Ruby asks before it reloads.
- **Stay in step.** After an update, the next page you open loads the new version, so an old copy of Ruby never talks to a new server.

### Also live in this version

- **Projects and tasks.** Create projects with a short key, number every task (for example OPS-12), set status, priority, assignee and due date, and work in a list or on a board. Drag cards between columns, or use the keyboard or the move buttons. **My tasks** shows what is assigned to you.
- **Labels, checklists and milestones.** Tag tasks with coloured labels, break a task into checklist steps, group work into milestones with a progress page, set a soft limit per board column, rename or hide columns per project, save your favourite filters as views, and edit up to 100 tasks at once.
- **Knowledge base.** Write pages in Markdown, organise them in a tree for the whole team or for one project, see the history of every page and restore an older version. If two people edit the same page, Ruby shows both versions instead of overwriting one.
- **Search.** One search box finds pages and tasks.
- **Comments, @mentions and notifications.** Comment on tasks and pages, mention a colleague with @, and get notified when you are mentioned, when someone comments on your task, or when a task is assigned to you.
- **Attachments.** Add files up to 25 MB to tasks and pages. Files are only available to signed-in people.
- **People.** The employee directory with profiles and an org chart. Sensitive HR details are visible only to people with HR access, and every view of them is logged.
